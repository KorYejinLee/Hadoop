# 프로젝트 소개
**빅데이터 단어 추출하여 정렬하기**

Hadoop MapReduce는 범용 하드웨어의 대규모 클러스터(수천 개의 노드)에서 엄청난 양의 데이터(수 테라바이트 규모의 데이터 세트)를 안정적이고 장애에 강한 방식으로 병렬로 처리하는 어플리케이션을 쉽게 작성할 수 있는 소프트웨어 프레임워크 입니다.<br><br>
WordCount 예제를 활용하여 주어진 입력 세트에서 각 단어가 나타난 횟수를 세고 value를 기준으로 정렬하고자 합니다.
